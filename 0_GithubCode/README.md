# 0_GithubCode — 共享代码与技能库

所有智能体共享的公共资源库。三级分离：

| 目录 | 职能 | 规则 |
|------|------|------|
| `1_Toys/` | 共享工具 | 日常运维脚本，直接执行 |
| `2_Codes/` | 代码仓库 | 含代码的项目、框架、官方源码，**只读不改** |
| `3_Skills/` | 技能说明 | 只放 SKILL.md、模板、示例文档，不含可执行代码 |
| `4_List/` | 清单索引 | 各类清单、对照表 |

## 核心纪律

1. **SKILL 与代码必须分开放**——含代码的 SKILL 拆开：SKILL.md 去 `3_Skills/Installed/`，代码全量去 `2_Codes/`。不破例。
2. 命名规范：目录首字母大写、下划线分隔（`1_Toys` 不是 `1-Toys`）。
3. 共享库更新前先讨论确认，涉及删除先备份。
4. 敏感信息（.env、密码）绝不进入共享区。

> 模板说明：教学版为目录壳，复制后按需填充。
