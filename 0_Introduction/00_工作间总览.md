# 00_工作间总览

> **文档版本**：v2.0（结构升级为三库）
> **适用对象**：所有共用工作间的智能体（协调者/助理智能体/业务智能体等）与使用者
> **使用者**：指本工作间的管理者与决策人，下同。
> **目的**：定义"共用工作间"的完整结构、各目录用途与归位规则，作为其他说明文档的总纲。

---

## 一、核心理念

> **软件/代码与用户数据分离，个性化设置与素材各归其位。**

| 概念 | 对应位置 |
|:---|:---|
| 软件本体（代码归代码） | 智能体运行环境（WSL / 系统侧） |
| 个性化设置 | `1_Memory/` |
| 素材库/项目 | `2_Projects/`（智能体互访共享，主战场） |
| 工程记录 | `4_Logs/`（WorkingLog & MaintainLog） |
| 笔记与剪藏 | `5_Notes/` |
| 成品输出 | 生成的文档/书籍/交付物 |

**编号体系仅供使用者（人）搜寻索引，智能体靠文件名检索，不受编号限制。**

---

## 二、共用工作间结构

```
AI_Studio/
├── 0_Introduction/            # 📖 说明书（00_总览 / 01_协作 / 02_日志规范 + 各智能体入门）
├── 1_Memory/                  # 🧠 角色设定与个性化（含各智能体角色子目录）
├── 2_Projects/                # 📦 项目工作区（所有智能体共用，实际干活主战场，核心）
├── 3_MeetingRoom/             # 🏛️ 公共讨论与公告
│   ├── Bulletin.md            #    全局公告板
│   ├── Discussions/           #    多方讨论文件
│   ├── Letters/               #    点对点信件
│   ├── Conclusions/           #    讨论定稿结论
│   └── Archive/               #    存档
├── 4_Logs/                    # 📋 日志归档（WorkingLog 每日 / MaintainLog 系统）
├── 5_Notes/                   # 🗒️ 笔记与剪藏（个人知识库）
├── ToolCode/                  # 🔧 可复用脚本库（01_文件与文档 … 05_系统与环境 / _misc / 下载工具）
├── SkillsLib/                 # 🤝 共享技能库（中文分类 + _备选 + 总索引）
└── GithubRepos/               # 📚 第三方整包仓库（只读、不改造）
```

> **共享资源库**（ToolCode / SkillsLib / GithubRepos）与工作间同级，无编号前缀；三者合称"三库"，是所有智能体共享的公共资源。
>
> **已废弃目录**：`0_GithubCode`（旧结构，已拆为三库）、`3_Tools`、`Harness`、`Library`/`VideoLibrary`、`5_To Clear`、各旧 `Studio for Hermes` 等。

## 三、各目录用途细则

| 目录 | 用途 | 访问 | 归属规则 |
|------|------|------|---------|
| `ToolCode/` | 我们写的可复用脚本 | 全员读，**登记责任人：协调者** | 按 01–05 分类；脚本名「动词_名词」；只进可复用件 |
| `SkillsLib/` | 共享技能库 | 全员读，**登记责任人：协调者** | SKILL.md 进中文分类；索引见 `02_清单与导航.md`；低频放 `_备选/` 并改名 `.off` |
| `GithubRepos/` | 第三方整包仓库 | 全员读，**只读不改造** | 要改就抄进 ToolCode 重写；本机已有等价能力的不留 |
| `0_Introduction/` | 说明书：总览/协作/日志规范 + 各智能体专属入门 | 说明文档由轮值管理员维护，其余只读 | 定稿文档带版本号 |
| `1_Memory/` | 角色设定、个人信息、设备配置、工作纪律、项目清单 | 各自读写自己的角色文件；公共模板只读 | 角色文件按 `<智能体名>` 子目录区分 |
| `2_Projects/` | 所有项目工作区（实际干活主战场）| **全员可读/可拷贝**；新建/删除目录需登记 | 新产出默认 `2_Projects/<项目名>/` |
| `3_MeetingRoom/` | 公共公告/讨论/信件/结论 | **全员可读可写（公共透明）** | 讨论文件、信件按规范命名，定稿移 Conclusions/ |
| `4_Logs/` | 日志（WorkingLog 每日 / MaintainLog 系统）| 本人追加自己的日志，他人只读 | 文件名 `WorkingLog_YYYY-MM_<前缀>.md` |
| `5_Notes/` | 笔记、剪藏、研究资料、OCR 产物 | 各自读写；敏感资料不入库 | 同类资料归子目录，不散放根下 |

## 四、归位规则（新产出默认路径）

1. **新项目/新文档** → 默认 `2_Projects/<项目名>/`，不在根目录散放。
2. **各智能体的新产出** → 一律写入共用工作间 `2_Projects/<项目名>/`。
3. **新增项目命名** → 见名知意 + 唯一性（新建前查 `目录登记表`），防重复目录。
4. **脚本** → 可复用的进 `ToolCode/` 对应分类；项目专用留项目 `2_项目代码/`。
5. **技能** → SKILL.md 进 `SkillsLib/<中文分类>/`；含代码的拆开放（代码进 `ToolCode/` 或 `GithubRepos/`，SKILL.md 里注明代码路径）。
6. **第三方仓库** → 进 `GithubRepos/`，只读引用。
7. **笔记与剪藏** → 进 `5_Notes/` 对应子目录。
8. **敏感文件（账号/密钥）** → **严禁入公共区**，各智能体私有区自管。
