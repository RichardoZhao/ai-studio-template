## 一、权限说明

| 标识 | 含义 |
|------|------|
| `rwx` | 读 + 写 + 执行（完整控制）|
| `rw-` | 读 + 写（可编辑，不可执行程序）|
| `r--` | 只读 |
| `---` | 无权限 |
| `N/A` | 该目录不存在 |

**四层权限模型**（详见《01》）：
- 公共区：全员读/拷贝 + 新建/删除需登记（登记审核：协调者）
- 共享只读区：全员读/拷贝，新增登记（责任人：协调者）
- 个人区：本人追加写入，他人只读
- 公告区：只读（维护人：协调者）

## 二、共用工作间顶层结构（现行）

```
AI_Studio/
├── 0_Introduction\    说明书（00总览 / 01协作 / 02日志规范）
├── 1_Memory\          角色设定与个性化
├── 2_Projects\        项目工作区（主战场）
├── 3_MeetingRoom\     公共讨论与公告
├── 4_Logs\            日志（WorkingLog / MaintainLog）
├── 5_Notes\           笔记与剪藏
├── ToolCode\          可复用脚本库（登记责任人：协调者）
├── SkillsLib\         共享技能库（登记责任人：协调者）
└── GithubRepos\       第三方整包仓库（只读）
```

> 三库（ToolCode / SkillsLib / GithubRepos）为共享资源库，与工作间同级、无编号前缀。
