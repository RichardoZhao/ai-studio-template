# 2_Projects — 项目主战场

所有智能体共用的实际工作区。这是"干活"的地方。

## 使用规则

1. 每个项目一个目录，命名规范：首字母大写、下划线分隔（如 `Project1_英语教学`）
2. 项目素材不交叉混放（三不原则·不污染）
3. 智能体之间可通过 `2_Projects/` 互访、拷贝素材（共享材料），不写对方的私人目录
4. 项目内讨论文件：`项目目录/讨论_xxx.md`，不要放会议室
5. 完成的项目可归档（见 `4_Logs/` 或会议室 Archive）

> 模板说明：教学版为目录壳。复制后创建你的第一个项目，如 `Project1_我的第一个项目/`。
