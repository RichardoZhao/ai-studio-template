# 4_Logs — 日志

SRE 级日志纪律（详见 `1_Memory/04_工作纪律.md` 第十五条）。

## WorkingLog（工作日志）

每天写一条，文件名 `YYYY-MM-DD.md`：

```markdown
# 工作日志 - YYYY-MM-DD

## 会话概要
1. 核心事件（按时间顺序）

## 新增/变更的要求
- 使用者今天提出的新规则、偏好变更

## 待办
- [ ] 待完成任务

---
📊 今日自评
- 完成度：XX%
- 困惑点：
- 明日重点：
- 异常标记：
```

> **每日启动时必读前一日工作日志**，衔接待办。

## MaintainLog（维护日志）

系统变更、报错、安装、配置修改时必写：

```markdown
# 维护日志 - YYYY-MM-DD

## 变更标题
### 问题描述
### 处理过程
### 最终结果
```

> 模板说明：教学版为目录壳，已含格式说明。
