# 5_Notes — 笔记与剪藏

个人知识库：读书笔记、网页剪藏、研究资料、OCR 产物。

| 子目录 | 用途 |
|---|---|
| `20_剪藏/` | 网页、文章、视频的剪藏与整理稿 |
| `10_读书笔记/` | 书籍/论文笔记 |
| `30_研究/` | 专题研究资料与产出 |
| `40_OCR产物/` | 扫描件 OCR 结果 |

## 规则

1. 只放**内容与资料**，可执行代码去 `ToolCode/`。
2. 敏感信息（账号、密钥、私人证件）不入库，或加密后另存私有区。
3. 命名见名知意；同类资料归入对应子目录，不散放根下。

> 模板说明：教学版为目录壳，复制后按需填充。
