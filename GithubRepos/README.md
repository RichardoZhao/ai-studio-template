# GithubRepos — 第三方整包仓库

从 GitHub 等渠道下载的第三方代码仓库。**只读、不改造**。

## 规则

1. **只读引用**：需要改动时，不直接改这里的源码——把需要的部分抄进 `ToolCode/` 重写，或另开项目目录。
2. **登记**：新增仓库登记进 `README.md` 总表（用途 / 体积 / 保留判据），并注明来源地址。
3. **本机已有等价能力的仓库不留**：如果本机已有同样能力的工具，仓库进回收站，只留一份能力。
4. **敏感信息**：仓库内不含密钥；如需配置，走环境变量。
5. **学习/教材类**：不参与运行的教程、教材仓库迁入 `SkillsLib/16_学习资料/`。
