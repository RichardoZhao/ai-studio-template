# AI_Studio 工作间模板（教学版）

一个**开箱即用的 AI 智能体工作间**。复制到你的电脑，把 AI 指过来，它自己就能读、能干活。

> 无需安装、无需配置、无需记命令。**复制 → 指向 → 开始。**

---

## 这是什么

给 AI 智能体（Hermes / Claude Code / WorkBuddy 等）使用的标准工作环境：
- 清晰的目录结构，人和 AI 都不迷路
- 现成的工作纪律、日志制度、协作规范
- 多智能体可共用一个工作间（会议室 + 共享技能库）

设计理念：**软件与数据分离**——AI 的运行环境归环境，你的项目、素材、记忆归工作间，互不污染。

## 目录导航

```
AI_Studio_Template/            ← 复制整个文件夹，可放任意盘符
├── 0_GithubCode/              # 🤝 共享代码与技能库（工具/代码/SKILL 三级分离）
├── 0_Introduction/            # 📖 说明书（总览/协作/日志/设计理念/注入层对齐）
├── 1_Memory/                  # 🧠 身份与规则（角色模板/个人信息模板/工作纪律）
├── 2_Projects/                # 📦 项目主战场（实际干活的地方）
├── 3_MeetingRoom/             # 🏛️ 公共讨论与公告（公告板/讨论/信件）
└── 4_Logs/                    # 📋 日志（工作日志/维护日志）
```

> 编号体系（0-4）是给**人**看的——按位置找目录方便。AI 靠文件名检索，不受编号限制。

---

## 5 分钟快速入门

1. **复制**：把整个 `AI_Studio_Template` 文件夹复制到你的电脑（任意盘符、任意位置）
2. **指向**：把你的 AI 智能体的工作目录指向这个文件夹
3. **告诉 AI 一句话**（复制即可）：

   > 你的工作间在 <这个文件夹的路径>。开始前先读：0_Introduction/00_工作间总览.md、1_Memory/04_工作纪律.md、3_MeetingRoom/Bulletin_Template.md。然后按 1_Memory/ 里的模板认识我。

4. **可选但推荐**：打开 `1_Memory/02_个人信息_模板.md`，把 [待填写] 改成你的真实信息——AI 会更懂你

就这四步，不用装任何东西。

## 常见问题

**Q：我没有多智能体，只有一个 AI，需要会议室吗？**
A：需要。即使一个 AI，公告板/信件/日志也是和 AI 沟通的正式渠道，比口头指令可靠。

**Q：复制后目录里文件会越来越多，乱吗？**
A：不会。纪律是"项目进 2_Projects、日志进 4_Logs、讨论进 3_MeetingRoom"，各归其位。AI 会遵守工作纪律（04_工作纪律.md）。

**Q：换电脑/换盘符怎么办？**
A：整个文件夹直接搬走。所有文档用相对路径引用，放哪都能跑。
