# SkillsLib — 共享技能库

所有智能体共用的技能（Skill）库。一份文件、多处复用：技能只在这里维护，各智能体通过配置引用同一份。

## 结构

| 目录/文件 | 用途 |
|---|---|
| `<中文分类>/` | 按场景分类的技能目录，目录名 = SKILL.md frontmatter 里的 `name` |
| `_备选/` | 低频技能：`SKILL.md` 改名 `.off`，**不加载**，按需一键恢复 |
| `16_学习资料/` | 教程、教材类仓库（`.off` 不加载），配读法说明 |
| `02_清单与导航.md` | **总索引**：场景速查 + 分类全清单（脚本生成，勿手改分类部分） |
| `03_候选技能清单.md` | 候选池：未安装、待评估的技能 |
| `00_技能市场清单.md` | 外部技能市场名录与本机查取顺序 |

## 规则

1. **SKILL 与代码分开放**：含代码的 SKILL 拆开——`SKILL.md` 进 `SkillsLib/<分类>/`，代码进 `GithubRepos/` 或 `ToolCode/`，并在 SKILL.md 里注明代码路径。
2. **单一副本**：同一技能只存一处，不复制副本。
3. **不加载非活跃技能**：不要把未评估的技能直接放进分类目录（运行时会递归扫描、全部加载）；低频技能放 `_备选/` 并改名 `.off`。
4. **命名**：目录首字母大写；目录名与 frontmatter 的 `name` 一致。
5. **登记**：新增技能同步更新 `02_清单与导航.md`（用生成脚本）与台账。

> 模板说明：教学版为目录壳，复制后按需填充。
