# ToolCode — 可复用脚本库

我们自己写的、可复用的脚本与工具。**只放可复用件，项目专用脚本留在项目里。**

## 分类

| 目录 | 内容 |
|---|---|
| `01_文件与文档/` | 文档处理、格式转换、Office 自动化 |
| `02_网络与抓取/` | 下载、抓取、归档、网络工具 |
| `03_音视频/` | 转码、剪辑、字幕、配音 |
| `04_数据与统计/` | 数据清洗、统计、报表、可视化 |
| `05_系统与环境/` | 环境配置、诊断、清理、部署 |
| `_misc/` | 暂不分类的杂项 |
| `下载工具/` | yt-dlp 等第三方下载器 |

## 规则

1. **命名**：文件名用「动词_名词」，如 `md_to_docx.py`、`link_archive_runner.py`。
2. **单一副本**：同一份脚本全机只存一处，跨处复用走引用，不复制副本。
3. **可复用才入库**：只服务单个项目的脚本留在该项目的 `2_项目代码/` 里。
4. **登记**：新增脚本登记进 `README.md` 的清单，注明用途、依赖、负责人。
5. **敏感信息**：密钥、账号一律不写入脚本，走环境变量或私有区。
